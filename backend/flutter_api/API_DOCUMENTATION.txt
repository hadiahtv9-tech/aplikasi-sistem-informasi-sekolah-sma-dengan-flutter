===============================================
FLUTTER UAS API DOCUMENTATION
===============================================

Base URL: http://192.168.1.4/flutter_api

All responses are in JSON format:
{
  "success": 1 (or 0),
  "data": {...},
  "error": "error message (if success=0)"
}

===============================================
AUTHENTICATION ENDPOINTS
===============================================

1. LOGIN
--------
POST /login.php

Parameters:
  - email (string, required)
  - password (string, required)

Response (success):
{
  "success": 1,
  "user": {
    "uid": "user_id",
    "email": "user@example.com",
    "username": "username",
    "nama": "Full Name",
    "role": "admin|guru|siswa"
  }
}

Example:
curl -X POST http://192.168.1.4/flutter_api/login.php \
  -d "email=admin@gmail.com&password=admin123"


2. REGISTER
-----------
POST /register.php

Parameters:
  - email (string, required)
  - password (string, required)
  - username (string, required)
  - name (string, required)
  - role (string, optional, default='siswa')

Response (success):
{
  "success": 1,
  "user": {
    "uid": "generated_uid",
    "email": "email",
    "username": "username",
    "name": "name",
    "role": "role"
  }
}


3. GET USER
-----------
GET /get_user.php?uid=user_id

Response (success):
{
  "success": 1,
  "user": {
    "uid": "user_id",
    "email": "email",
    "username": "username",
    "nama": "name",
    "role": "role",
    "kelas_id": null,
    "wali_kelas_id": null
  }
}

Parameters:

===============================================
ERROR RESPONSES
===============================================

All errors return:
{
  "success": 0,
  "error": "Error message describing what went wrong"
}

HTTP Status Codes:
  200 - Success
  400 - Bad request (missing parameters)
  404 - Not found
  500 - Server error (database connection, etc.)
